# CSCI4410 — OLA2

Personal portfolio and CV web pages built with HTML and CSS for CSCI4410 at Middle Tennessee State University.

## Pages

- **ola1.html** — Portfolio page with about, interests, hobbies, and favorite movies.
- **ola2.html** — Curriculum Vitae (CV) with profile, work experience, education, and skills.

## Tech

- HTML5
- CSS3 (custom styling with beige/brown theme)
- Google Fonts (Playfair Display, DM Sans)
- Font Awesome icons

## How to Run

Open `ola1.html` in any web browser. Use the nav links to switch between pages.

```
git clone https://github.com/your-username/CSCI4410-ola2.git
cd CSCI4410-ola2
```

Then double-click `ola1.html`.
